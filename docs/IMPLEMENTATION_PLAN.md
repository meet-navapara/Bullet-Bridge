# ORBIT BLAST — Implementation Plan

Starting point: empty directory (no existing project). Created with
`flutter create --org com.orbitblast --project-name orbit_blast --platforms android,ios`.

Toolchain found: Flutter 3.47.7 / Dart 3.13.5, Android SDK 36, JDK 21,
physical Pixel 8a (Android 17) connected. No macOS/Xcode (iOS cannot be built here).
No Python (asset generators are written in Dart).

## Approach

* **Pure-Dart simulation** (`lib/game/sim/`) owns all gameplay rules: fixed
  120 Hz timestep, balls, bullets, coins, power-ups, waves, collisions,
  rewards. It has no Flutter/Flame imports so it is fully unit-testable and
  deterministic for a given seed.
* **Flame** (`lib/game/orbit_blast_game.dart`) drives the loop, feeds input,
  renders the simulation with Canvas, and plays cosmetic particles.
* **Flutter widgets** for HUD and every menu; HUD listens to small
  `ValueNotifier`s that only change when values change (no per-frame rebuilds).
* **Persistence**: one versioned JSON document in `shared_preferences`,
  written through `SaveRepository` with a backup key and migration.
* **Economy/progression** rules live in plain classes (`lib/economy`,
  `lib/progress`) with a single balance config (`lib/config/balance.dart`).
* Audio is procedurally generated by `tool/generate_audio.dart` (original,
  no third-party sounds); icon rendered by `tool/render_icon_test.dart`.
* Ads: `google_mobile_ads` with UMP consent, Google test IDs in debug, real
  IDs only via `--dart-define`; ads disabled when IDs are missing.

# Phase 2 — BOOMFORGE rebuild (2026-10-27)

The game was re-directed to BOOMFORGE: an original 2.5D cartoon presentation
built around elemental chain reactions. The tested foundations (fixed-step
simulation, saves, economy, audio, ads, menus) were kept and extended; the
gameplay layer, art and UI style were rebuilt.
